## ⚛️ Recent work: ECDSA.fail

<table>
<tr>
<td width="60%">

[**ECDSA.fail**](https://ecdsa.fail) is an open challenge to build the cheapest quantum circuit that adds a point on
**secp256k1**, Bitcoin's elliptic curve. It is scored by *Toffoli count × qubits*.

I hold the **officially scored best Toffoli count at 11 widths (774–785 qubits)**, with up to
**170,316 fewer Toffolis** than the previous rows. Every row passed all 9,024 validation shots.

👉 [**Read the write-up**](https://github.com/binharold/ecdsafail-challenge/blob/main/RESULTS.md)

</td>
<td width="40%" align="center">

| Qubits | Toffolis saved |
|:---:|---:|
| 780 | **−170,316** |
| 779 | **−157,903** |
| 783 | **−104,107** |
| 782 | **−102,500** |
| 781 | **−102,190** |
